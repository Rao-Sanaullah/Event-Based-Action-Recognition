Abstract

We propose a unified framework for event-based object and fine-grained object-action recognition using neuromorphic vision data. The approach combines spike-based representations, hierarchical modeling, and ensemble learning to capture temporal dynamics. A real-time GUI enables step-wise visualization of prediction confidence, providing interpretability for temporal decision-making.

Method Overview

Event streams are converted into fixed-length spike-count tensors and processed using a hierarchical classification pipeline. The system first predicts object categories and then refines predictions into fine-grained object-action classes. Ensemble learning improves robustness, while polarity-aware encoding enhances motion representation.

Dataset

Experiments are conducted on event-based manipulation datasets including E-MAD and a larger UGR dataset. These datasets contain human-object interaction sequences recorded using event cameras, enabling evaluation of both object-level and fine-grained action recognition.
