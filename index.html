Abstract

This work presents a unified framework for event-based object and fine-grained object-action classification using neuromorphic vision data. We evaluate performance across datasets of varying scale and complexity, transitioning from hand-cropped event streams to full-frame recordings. The proposed approach integrates spike-based representations, hierarchical modeling, and ensemble learning to capture both coarse and fine-grained interaction patterns. An interactive GUI tool is introduced for real-time visualization of model predictions and temporal confidence evolution. The results highlight the importance of dataset scale, representation design, and temporal modeling for robust real-world event-based perception.

Key Contributions

  • Event-based object and fine-grained action classification
  • Hierarchical meta-ensemble learning
  • Polarity-aware event representation
  • Large-scale dataset evaluation (UGR)
  • Interactive real-time GUI visualization tool

Datasets

E-MAD: Hand-cropped event streams for controlled evaluation.
UGR Dataset: Large-scale full-frame recordings with richer dynamics.

Interactive GUI Demonstration

The GUI replays event sequences step-by-step and visualizes model confidence evolution over time. It enables analysis of early predictions, ambiguity, and failure cases.
