Abstract

We present a unified framework for event-based object and fine-grained object-action classification using neuromorphic vision data. The method integrates spike-based representations, hierarchical modeling, and ensemble learning to capture temporal dynamics. An interactive GUI enables real-time visualization of model predictions and confidence evolution.
